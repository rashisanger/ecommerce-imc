# 🛒 IMC E-Commerce Platform (MERN Stack)

A **full-stack MERN e-commerce application** featuring secure authentication, role-based admin access, scalable backend APIs, and a modern responsive frontend.  
Designed to simulate a **production-ready e-commerce system** with real-world features.

---

## 🚀 Features

### 🔐 Authentication & Authorization
- JWT-based user authentication
- Role-based access control (Admin & User)
- Protected routes for admin dashboard
- Secure session handling

### 🧑‍💼 Admin Dashboard
- Role-based admin access
- Product, order, and user management
- Reduced unauthorized access and improved operational efficiency
- Faster order handling and management

### 🛍️ Product Management
- Full **CRUD operations** for products
- Advanced filtering, sorting, and pagination
- Keyword-based product search
- Optimized product retrieval (~30–40% faster)

### 🛒 Cart & State Management
- Centralized state management using **Redux Toolkit**
- Cart functionality for both guest and logged-in users
- Persistent cart and authentication state

### ☁️ Image & Media Handling
- Integrated **Cloudinary** for cloud-based image upload and delivery
- Reliable image performance in production environments

### 💳 Payments
- Secure payment processing using **Razorpay**
- Order confirmation after successful transactions
